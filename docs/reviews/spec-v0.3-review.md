# Adversarial review of SPEC v0.3

Verdict: **FIX-THEN-SHIP**; the API corrections and narrower v1 are sound, but submission recovery is not yet safe to implement as written.  
Submission gate: Do not attribute an indistinguishable text/URL attempt to this POST, or recover a journal that another process is still executing.  
Filesystem gate: Complete the move, destination-lock, and identity-removal protocols so their guarantees hold across processes.  
Correctness gate: Preserve query-specific cached values, close invalidation gaps, and fix the governor, all-day end dates, and remaining output contracts.  
Release gate: Correct the findings below before accepting the affected packages; the owner's confirmed Canvas access remains resolved.

Reviewed on 2026-09-09 against `docs/SPEC.md` v0.3, SHA-256 `c97170a745fd24cc148145007b887dca12b4949705ad6187651ba24c794c75a1`. Line references below refer to that specification. The review covers every round-2 ID and all 32 round-1 IDs carried forward as partially resolved in [round 2](spec-v0.2-review.md). No round-1 item was marked still open there. Appendix E was checked against the substantive text.

This is a specification/source review, with no implementation, account operations, submissions, downloads, platform builds, or runtime attack tests. Previously confirmed API behavior is marked **unchanged**, not re-confirmed wholesale. Focused checks of newly introduced assumptions use the same [Canvas source commit][canvas-commit] and primary filesystem/SQLite/RFC documentation. Counterexamples are deductions from these contracts, not reported failures on the owner's account.

“Resolved” means the original contract defect is fixed or expressly deferred, not that implementation tests have run. A resolved row can identify a separate regression introduced by the new design. The new finding table uses the same severity meanings and columns as the previous reviews.
