# Release review

Source builds are documented in [README.md](../README.md). Package-install
routes are not verified publication routes. Rolf reviews changes and controls
publication. Coding agents must not commit, tag, or push.

## Prepared packaging

- `dist-workspace.toml` configures cargo-dist 0.32.0, archives, checksums, and
  a Homebrew formula. The Homebrew publish job is disabled.
- `.github/workflows/release.yml` is generated by cargo-dist.
- `.github/workflows/build-setup.yml` generates man pages and completions.
- `xtask/src/dist_assets.rs` generates assets and patches formula install paths.
- `release-plz.toml` and `CHANGELOG.md` configure version and release notes.
- The three library and CLI crates have `publish = false`. crates.io publishing
  is not enabled.

The configured targets are `aarch64-apple-darwin`, `x86_64-apple-darwin`,
`x86_64-unknown-linux-musl`, `aarch64-unknown-linux-musl`, and
`x86_64-pc-windows-msvc`. Configuration is not evidence that all targets work.
Archives include both licenses, the README, the skill, man pages, and completions.

## Checks before publication

```sh
just check
cargo +1.88 check --workspace --all-targets
npm --prefix extension test
cargo xtask dist-assets --out target/dist-assets
```

Use a short, private temporary root for socket tests. See
[testing.md](testing.md). Complete the dependency/advisory check with its required
metadata and advisory database in a review environment that permits network Git.
Do not report an offline check with missing dependencies as a pass.

Rolf should review the final diff and the history intended for GitHub separately.
The tree review does not remove historical secrets. The uncertain fixtures were
replaced with documented invented data. Revoke any former example credentials
that were real. No real account data belongs
in the repository, even after automatic sanitization.

## Local packaging, without publication

These commands require cargo-dist 0.32.0 in addition to the source prerequisites:

```sh
cargo xtask dist-assets --out target/dist-assets
dist plan
dist build --artifacts=local --target "$(rustc -vV | awk '/^host:/ {print $2}')"
dist build --artifacts=global
cargo xtask dist-formula --formula target/distrib/canvas-lms-cli.rb
```

`just dist-assets`, `just dist-plan`, and `just dist-build` wrap the first three
steps. Global artifacts built outside a release can lack formula checksums.
`dist-formula` refuses templates it does not recognize. Review its output before
publication. No packaging command above was rerun in this publication cleanup.

## Historical packaging evidence

The September 10, 2026 report recorded a host-target archive with `canvas`,
51 man pages, and 5 completion scripts on `aarch64-apple-darwin`. It also
recorded `dist plan`, global artifacts, formula patching, and a successful
`ruby -c` syntax check. These results were not rerun during this cleanup.
The report did not run a source Homebrew install. Homebrew audit and style
commands failed while loading Homebrew's vendored JSON gem, before reading
the formula.

Signing, notarization, clean-machine package installs, and cross-platform builds
remain release work. Do not advertise a Homebrew, crates.io, or archive install
as available until that route has been published and checked.
